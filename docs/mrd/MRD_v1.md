## 2. 背景与问题定义

### 2.1 问题

电商商家需要大量商品视觉素材（主图、场景图、细节图、活动图），现有供给方式都有明显短板：

| 方式 | 成本 | 周期 | 瓶颈 |
|---|---|---|---|
| 实拍 + 修图 | 高 | 长（天级） | SKU 一多就排不过来，改一次重拍一次 |
| 通用 AI 生图 | 低 | 短 | **商品主体会被改形**，风格每次都漂，无法批量 |
| 电商设计 SaaS | 中 | 短 | 只能做模板贴图，生成能力弱 |
| 垂直 AI 商拍 | 中高 | 短 | 按张计费贵、闭源不可定制 |
| 自建 ComfyUI | 低（GPU） | — | **门槛高、批量易崩、没有质量与成本度量** |

### 2.2 问题的本质

不是"能不能生成图"，而是能不能**稳定、批量、可度量、成本可控**地产出**商品主体不变形**的图。
前者已被解决，后者没有 —— 这正是本项目的切入点。

## 3. 市场分析

### 3.1 驱动因素

| 因素 | 说明 |
|---|---|
| 电商存量竞争 | 视觉素材从"展示"变成"转化抓手"，需求量与更新频率持续上升 |
| SKU 长尾化 | 大量中小商家长尾 SKU 无法负担实拍成本 |
| 生成模型成熟 | SD / FLUX 等开源模型质量已商用可用，且**可私有化部署**（成本可控） |
| 合规意识提升 | 商用许可、生成标识成为选型要素 —— 有利于可解释的自建方案 |

### 3.2 趋势（2026）

1. **从"玩具"到"工具"**：生图不再用于炫技，而是嵌入生产流程，要求稳定与可复现。
2. **从"单图"到"批量"**：一次生成一张没有意义，要的是一次出几百张且质量一致。
3. **从"文生图"到"参考图编辑"**：保真需求推动以图生图、多参考图编辑成为主流。
4. **从"工具"到"智能体"**：自动选参、自动质检、自动重跑的闭环正在形成（本项目 V3 的 Agent 方向）。

> ⚠️ **待核实**：市场规模、增长率等量化数据暂缺权威来源，本版不填占位数字。
> 补充渠道：行业报告、券商研报、平台公开数据。

## 5. 竞品与机会

详见 `competitive_analysis.md`。核心结论：

> **市场两极分化，中间是空档。**
> 一极门槛低但不可控（通用生图 / 设计 SaaS），另一极可控但门槛高（ComfyUI 社区）。
> 本项目填补中间档：**用 ComfyUI 的可控性与开源成本，做到垂直商拍的保真与易用。**

## 6. 产品定位

**一句话**：面向电商商家的 AIGC 视觉量产平台 —— 上传商品图，选模板，批量产出可直接上架的素材，
全程可追溯、可复现、成本可核算。

**三个差异化支柱**

| 支柱 | 含义 | 对应能力 |
|---|---|---|
| **保真** | 商品主体不变形，风格不漂 | 控制矩阵、参考图锁定、主体保真专项 |
| **量产** | 一次出几百张，无人值守 | 异步队列、断点续跑、OOM 自动降级 |
| **可度量** | 良品率、成本、耗时有数 | golden set、良品率看板、单张成本模型 |

## 7. 产品目标与成功指标

### 7.1 北极星指标

> **周有效交付图片数** = 用户生成且**下载/采纳**的图片数

选它的理由：同时反映用户量 × 使用深度 × 质量满意度 × 产能，
且**必须下载才算**，无法靠刷量作弊。

### 7.2 V1 目标（可验收）

| 指标 | 目标 | 测量方式 |
|---|---|---|
| 任务成功率 | ≥98% | 后端埋点（排除用户取消） |
| 良品率 | ≥80% | golden set + 抽样人工评分 |
| 单卡稳定性 | 8h 混合压测零崩溃 | P9-05 |
| 批量能力 | 1000 张无人值守完成 | P6-05 |
| 内测验证 | ≥5 人内测，≥3 人愿继续使用 | P12-05 |
| 成本 | 单张成本已知且可核算 | P9-09 |

### 7.3 商业化目标（V2 起验证）

| 指标 | 目标 | 备注 |
|---|---|---|
| 单张成本 | 显著低于垂直商拍按张计费 | 需 P9-09 后测算 |
| 付费转化 | 待定 | V2 引入计费后再定 |

## 8. 解决方案概述

### 8.1 能力矩阵（V1）

| 层 | 能力 |
|---|---|
| 工作流 | 文生图 / 图生图 / 高清修复 / 局部重绘 / 风格迁移 / 批量出图 |
| 控制 | ControlNet 全套、IP-Adapter、LoRA、SAM 自动遮罩、DWPose、景深/线稿/法线 |
| 平台 | 异步任务队列、用户与配额、素材管理、画廊、批量向导 |
| 质量 | 评测集、良品率看板、自动质检、缺陷知识库 |
| 工程 | 可复现（版本 + hash + 元数据）、可回滚、可观测、成本核算 |
| 底模 | SDXL 1.0（主）+ FLUX.2 [klein] 4B（辅，Apache-2.0） |

### 8.2 版本路线

| 版本 | 周期 | 主题 |
|---|---|---|
| V1 | 2026-09 ~ 11 | 电商视觉量产闭环 |
| V2 | 2026-11 ~ 2027-01 | 一致性与平台化（IP 一致性、场景合成、团队协作、开放 API、计费、LLM 助手） |
| V3 | 2027-01 ~ 03 | 视频与智能化（AI 视频、Agent 自评闭环、多机多卡、模板市场） |

## 11. 成功的前提（必须同时成立）

1. 商品主体保真达标 —— 否则图不能上架，一切归零
2. 良品率 ≥80% —— 否则人工筛选成本吃掉收益
3. 单张成本低于替代方案 —— 否则没有商业价值
4. 非技术用户能自助完成 —— 否则无法规模化
