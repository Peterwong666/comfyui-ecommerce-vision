# 竞品分析

> 版本：v1.0 · 日期：2026-09-15 · 作者：Peterwong666
> **数据说明**：评分为基于公开资料与产品体验的**定性判断**（1-5 分），用于找定位空隙，
> 不作为对外引用数据。标注「待实测」的项将在 P5-02 / P8 阶段用我们的评测集校准。

## 1. 竞品分类

把市面上的玩家按「服务谁、解决什么」分成四类，而不是按技术路线分 ——
因为用户选工具时是**按场景选**，不是按 SD 还是 Diffusion Transformer 选。

| 类别 | 代表产品 | 核心价值 | 致命短板（对电商量产而言） |
|---|---|---|---|
| **A. 通用生图工具** | Midjourney、即梦、通义万相 | 画质高、审美在线 | 商品主体会被改形、无法批量、无 API 量产、风格每次都漂 |
| **B. 电商设计 SaaS** | 美图设计室、稿定设计、Canva AI | 模板多、上手快、贴合电商规范 | 生成能力弱、主体保真差、只能做"贴图式"组合，谈不上量产 |
| **C. SD/ComfyUI 社区平台** | LiblibAI、吐司、Civitai | 工作流丰富、可控性最强、免费 | 面向爱好者，无任务管理、无良品率、无成本核算、批量易崩 |
| **D. 垂直 AI 商拍** | 各 AI 商拍 SaaS | 主体保真好、开箱即用 | 闭源黑盒、按张收费贵、无法定制、风格同质化 |
| **E. 专业设计工具集成** | Adobe Firefly、PS 创成式填充 | 融入既有设计流程、训练数据授权清晰 | 无批量量产能力、订阅贵 |

## 2. 五维评分

维度选择依据：电商视觉量产的**决策链**就是这五件事，缺一不可。

| 产品类别 | 主体保真 | 可控性 | 批量量产 | 单张成本 | 上手门槛 | 综合 |
|---|---|---|---|---|---|---|
| A. 通用生图 | 2 | 2 | 1 | 3 | **5** | 2.6 |
| B. 电商设计 SaaS | 3 | 2 | 3 | 3 | **5** | 3.2 |
| C. SD/ComfyUI 平台 | 4 | **5** | 2 | **5** | 1 | 3.4 |
| D. 垂直 AI 商拍 | **5** | 3 | 4 | 2 | **5** | **3.8** |
| E. 专业设计工具 | 4 | 4 | 2 | 2 | 3 | 3.0 |
| **本项目目标** | **4-5** | **5** | **5** | **5** | **4** | **4.6** |

> 说明：D 类（垂直商拍）是唯一综合分接近 4 的，说明「主体保真 + 开箱即用」确实是真需求，
> 但它的成本与不可定制是硬伤。本项目的机会正在于**用 C 类的可控性与成本，做到 D 类的保真与易用**。

## 3. 关键洞察

### 洞察 1：市场被"两极分化"，中间是空档

- 一极是**门槛低但不可控**（A/B/D 类），用户爽但生产不了；
- 另一极是**可控但门槛高**（C 类），能生产但只有极客能用。
- **中间档缺位**：既可控、又不需要懂节点、还能批量跑的东西。
- → 本项目的定位就在这个空档：**把 C 类的能力，包装成 B 类的体验，加上 D 类的保真。**

### 洞察 2：「主体保真」是电商场景的一票否决项

通用生图工具再好看，只要把商品 Logo 画歪、把瓶身弧度改了，图就废了。
这不是"画质"问题，是**可用性**问题。
- → 所以 V1 的 P4-10「商品主体保真专项」必须做，且要单独立项评测。

### 洞察 3：C 类平台证明了需求，但没解决"生产"

LiblibAI / 吐司上大量电商相关工作流的存在，说明**需求是真实的**；
但这些平台只提供「工作流分享」，不提供「任务管理、良品率、成本核算」。
- → 这三项正是"工具"与"生产系统"的分界线，也是本项目工程侧的主要价值。

### 洞察 4：按张收费的模式给自建留了空间

D 类按张计费（单价较高），当 SKU 数量上来后成本线性增长；
自建方案是**固定 GPU 成本 + 边际成本递减**。
- → 这直接支撑我们的成本模型（P9-09）与商业模式假设。

## 4. 差异化定位

| 维度 | 竞品做法 | 本项目做法 |
|---|---|---|
| 底层 | 闭源黑盒 / 裸 ComfyUI | **ComfyUI 引擎 + 自研生产层**，能力可解释、可调优 |
| 一致性 | 靠运气或固定模板 | **参考图锁定 + seed 复用 + 控制矩阵**，多图风格不漂 |
| 批量 | 不支持 / 易崩 | **异步队列 + 断点续跑 + OOM 自动降级** |
| 质量 | 无度量 | **golden set + 良品率看板 + 缺陷知识库** |
| 成本 | 不透明 / 按张贵 | **GPU 秒 → 单张成本模型**，成本可核算 |
| 可追溯 | 无 | **工作流版本 + 模型 hash + 全参数入元数据** |
